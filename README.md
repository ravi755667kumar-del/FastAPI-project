ANN Customer Churn Prediction API

A production-ready machine learning API built with **FastAPI**, **TensorFlow/Keras**, and **Scikit-learn**, fully containerized using **Docker**. 

This application serves an Artificial Neural Network (ANN) that predicts whether a bank customer is likely to churn based on their financial and demographic profile.

---

## 🚀 Tech Stack
* **Web Framework:** FastAPI (with Pydantic V2 data validation)
* **Deep Learning:** TensorFlow / Keras (`.keras` model)
* **Preprocessing:** Scikit-learn `StandardScaler` (`.pkl`)
* **Containerization:** Docker (Python 3.10-slim)
